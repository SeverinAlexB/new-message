# Überblick

<a id="p1"></a>*Der neue Weg nach vorn für die Menschheit* ist ein kommendes neues Buch der Neuen Botschaft, das von New Knowledge Library veröffentlicht werden soll. Vor der Veröffentlichung werden die folgenden Kapitel online zugänglich gemacht.

<a id="p2"></a>Erhaltet eine Mitteilung per E-Mail, sobald das neue Buch erhältlich und kostenlos online verfügbar sein wird, indem ihr euch hier in unsere E-Mail-Liste eintragt.
