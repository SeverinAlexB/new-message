# The Allies of Humanity & Greater Community Teachings — Master Index

A corpus index for the four-book *Allies of Humanity* Briefings and related Greater Community teachings. The Briefings address humanity's emergence into a populated Greater Community and a covert extraterrestrial Intervention seeking Earth's resources and allegiance through persuasion rather than force. *Greater Community Spirituality* and *Wisdom From the Greater Community, Volume I* provide theological, practical, and devotional frameworks behind many of the Briefings' core terms, especially Knowledge, preparation, purpose, Spiritual Family, and the Unseen Ones.

## How to use this index

- This file is the cross-book master: chapter map for all four Allies books plus GCS and WFGC1, with a merged A–Z concept index keyed by book and chapter.
- For per-chapter summaries and per-book concept indexes, see the `index.md` inside each directory.
- Concept refs use the form **B`<n>`: `<chapter-prefix>`**, **GCS: `<chapter-prefix>`**, or **WFGC1: `<chapter-prefix>`**, where the chapter prefix is the leading two-digit number (e.g. `01`, `04`, `08`). To resolve a prefix to a filename, see the chapter map below or the per-book index.
- Books are abbreviated as **B1**, **B2**, **B3**, **B4**, **GCS**, and **WFGC1** throughout.

```bash
# Find every passage mentioning "Pacification Program" across all books
grep -ril "Pacification Program" book-*-*/

# Show every chapter file in one book
ls book-1-allies-of-humanity/*.md

# Find passages about hybrids in a specific book
grep -in "hybrid" book-2-human-unity-and-freedom/*.md
```
