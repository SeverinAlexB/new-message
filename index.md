# The Allies of Humanity — Master Index

A four-book series of "Briefings" by Marshall Vian Summers (1996–2016) addressing humanity's emergence into a populated Greater Community and a covert extraterrestrial Intervention seeking Earth's resources and allegiance through persuasion rather than force. The Briefings are framed as transmissions from a hidden multi-racial expedition (the Allies) sent on behalf of the Unseen Ones / Higher Powers.

## How to use this index

- This file is the cross-book master: chapter map for all four books plus a merged A–Z concept index keyed by book and chapter.
- For per-chapter summaries and per-book concept indexes, see the `index.md` inside each book directory.
- Concept refs use the form **B`<n>`: `<chapter-prefix>`**, where the chapter prefix is the leading two-digit number (e.g. `01`, `04`, `08`). To resolve a prefix to a filename, see the chapter map below or the per-book index.
- Books are abbreviated as **B1**, **B2**, **B3**, **B4** throughout.

## Searching the corpus

Use `grep` directly against the source files for verbatim phrase search:

```bash
# Find every passage mentioning "Pacification Program" across all books
grep -ril "Pacification Program" book-*-*/

# Show every chapter file in one book
ls book-1-allies-of-humanity/*.md

# Find passages about hybrids in a specific book
grep -in "hybrid" book-2-human-unity-and-freedom/*.md
```

For concept-level lookup (which chapters discuss a theme), use the master concept index above, then open the per-book index for the chapter summary, then read the chapter file itself.
